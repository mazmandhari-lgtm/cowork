# سِتر — متجر عبايات إلكتروني

متجر إلكتروني لبيع العبايات، مبني بـ Next.js وTailwind CSS، بتصميم مستوحى
من أسلوب آبل (Apple.com): مساحات بيضاء واسعة، طباعة كبيرة وواثقة، صور منتج
مركزية، وانتقالات وحركات ظهور سلسة عند التمرير. الواجهة بالكامل باللغة
العربية باتجاه RTL، والأسعار بالريال العُماني (ر.ع.).

## المزايا

- **الصفحة الرئيسية** — قسم استهلالي (Hero) كبير، عرض للتصنيفات، أقسام
  منتجات مميزة بالتناوب (شبيهة بصفحات منتجات آبل)، مختاراتنا، ونشرة بريدية.
- **صفحة المتجر** (`/shop`) — تصفية حسب التصنيف (تُبنى تلقائيًا من بيانات
  المنتجات في `lib/products.ts`) وترتيب حسب السعر.
- **صفحة تفاصيل المنتج** (`/shop/[slug]`) — اختيار المقاس والكمية،
  الإضافة إلى السلة أو الشراء المباشر، ومنتجات ذات صلة.
- **سلة التسوق** (`/cart`) — تُحفظ في `localStorage` وتبقى بعد إعادة تحميل الصفحة.
- **إتمام الطلب** (`/checkout`) — نموذج شحن وطريقة دفع (نموذج تجريبي، بلا
  بوابة دفع حقيقية بعد).
- **قصتنا** (`/about`) — قصة العلامة، دليل المقاسات، سياسة الشحن والإرجاع، والتواصل.

## قاعدة البيانات (Supabase)

المنتجات والطلبات مخزّنة في Supabase (Postgres)، وليست بيانات ثابتة في الكود.

1. افتحي مشروعك في [supabase.com](https://supabase.com)، اذهبي إلى
   **SQL Editor > New query**، الصقي محتوى الملف
   `supabase/migrations/0001_init.sql` واضغطي **Run**. هذا ينشئ جدولي
   `products` و`orders` مع صلاحيات القراءة/الكتابة العامة المناسبة (RLS)،
   ويزرع المنتجات الخمسة الحالية.
2. لإضافة أو تعديل منتج لاحقًا: **Table Editor > products** من داخل لوحة
   Supabase، بدون الحاجة لتعديل الكود أو إعادة نشر الموقع.
3. الطلبات المُرسلة من صفحة إتمام الطلب تُحفظ تلقائيًا في جدول `orders`
   (بالإضافة إلى رسالة واتساب، وليس بدلًا منها) — راجعيها من
   **Table Editor > orders**.

## التشغيل محليًا

```bash
cp .env.local.example .env.local
# افتحي .env.local وأضيفي رابط مشروعك ومفتاح anon من
# Project Settings > API في لوحة Supabase

npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) لعرض الموقع.

## صور المنتجات

الصور الفعلية للمنتجات موجودة في `public/products/` وهي صور تسويقية جاهزة
(تتضمن اسم القطعة والسعر وزر "ORDER NOW" مصممًا داخل الصورة نفسها). عند
إضافة منتج جديد من لوحة Supabase، ارفعي صورته إلى هذا المجلد في الكود
واربطيها عبر حقل `image` (مثال: `/products/my-product.jpg`). يُفضّل ضغط
الصور الكبيرة قبل رفعها (على سبيل المثال عبر `sharp`) للحفاظ على سرعة
تحميل الموقع.

## النشر (Vercel)

الموقع موقع Next.js حقيقي يحتاج خادمًا (لم يعد تصديرًا ثابتًا)، لذلك يُنشر
عبر [Vercel](https://vercel.com):

1. من لوحة Vercel: **Add New > Project**، واختاري هذا المستودع.
2. أثناء الإعداد أضيفي متغيرَي البيئة:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
3. اضغطي **Deploy**. كل دفعة (push) جديدة على الفرع الرئيسي تُنشر تلقائيًا.

## الخطوات التالية للإطلاق الفعلي

- ربط بوابة دفع حقيقية تدعم عُمان (مثل Thawani أو Tap) في صفحة `/checkout`.
- تصوير منتج إضافي لكل قطعة (زوايا متعددة، تفاصيل قريبة) بدل الاعتماد على صورة واحدة.
- إضافة نظام حسابات المستخدمين وتتبع الطلبات.
