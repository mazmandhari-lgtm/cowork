# سِتر — متجر عبايات إلكتروني

متجر إلكتروني لبيع العبايات، مبني بـ Next.js وTailwind CSS، بتصميم مستوحى
من أسلوب آبل (Apple.com): مساحات بيضاء واسعة، طباعة كبيرة وواثقة، صور منتج
مركزية على خلفيات متدرجة ناعمة، وانتقالات وحركات ظهور سلسة عند التمرير.
الواجهة بالكامل باللغة العربية باتجاه RTL.

## المزايا

- **الصفحة الرئيسية** — قسم استهلالي (Hero) كبير، عرض للتصنيفات، أقسام
  منتجات مميزة بالتناوب (شبيهة بصفحات منتجات آبل)، الأكثر مبيعًا، ونشرة بريدية.
- **صفحة المتجر** (`/shop`) — تصفية حسب التصنيف (يومية، مناسبات، سفر،
  إحرام وصلاة) وترتيب حسب السعر.
- **صفحة تفاصيل المنتج** (`/shop/[slug]`) — اختيار اللون والمقاس والكمية،
  الإضافة إلى السلة أو الشراء المباشر، ومنتجات ذات صلة.
- **سلة التسوق** (`/cart`) — تُحفظ في `localStorage` وتبقى بعد إعادة تحميل الصفحة.
- **إتمام الطلب** (`/checkout`) — نموذج شحن وطريقة دفع (نموذج تجريبي، بلا
  بوابة دفع حقيقية بعد).
- **قصتنا** (`/about`) — قصة العلامة، دليل المقاسات، سياسة الشحن والإرجاع، والتواصل.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) لعرض الموقع.

## ملاحظة حول الصور

بدلًا من صور فوتوغرافية حقيقية، يستخدم الموقع رسوماً توضيحية SVG بسيطة
(`components/AbayaArt.tsx`) لكل عباية بألوانها المختلفة — أسلوب مسطّح
ونظيف يتماشى مع الهوية البصرية المطلوبة دون الاعتماد على صور خارجية.
لإطلاق المتجر فعليًا، استبدل هذه الرسوم بصور منتج حقيقية عبر `next/image`.

## الخطوات التالية للإطلاق الفعلي

- ربط بوابة دفع حقيقية (مثل Moyasar أو Tap أو Stripe) في صفحة `/checkout`.
- إضافة صور منتج حقيقية.
- ربط قاعدة بيانات أو نظام إدارة محتوى لإدارة المنتجات بدلاً من `lib/products.ts`.
- إضافة نظام حسابات المستخدمين وتتبع الطلبات.
