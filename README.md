# سِتر — متجر عبايات إلكتروني

متجر إلكتروني لبيع العبايات، مبني بـ Next.js وTailwind CSS، بتصميم مستوحى
من أسلوب آبل (Apple.com): مساحات بيضاء واسعة، طباعة كبيرة وواثقة، صور منتج
مركزية، وانتقالات وحركات ظهور سلسة عند التمرير. الواجهة بالكامل باللغة
العربية باتجاه RTL، والأسعار بالريال العُماني (ر.ع.).

## المزايا

- **الصفحة الرئيسية** — قسم استهلالي (Hero) كبير، عرض للتصنيفات، أقسام
  منتجات مميزة بالتناوب (شبيهة بصفحات منتجات آبل)، مختاراتنا، ونشرة بريدية.
- **صفحة المتجر** (`/shop`) — تصفية حسب التصنيف (تُبنى تلقائيًا من بيانات
  المنتجات في `lib/products.ts`) وترتيب حسب السعر.
- **صفحة تفاصيل المنتج** (`/shop/[slug]`) — اختيار المقاس والكمية،
  الإضافة إلى السلة أو الشراء المباشر، ومنتجات ذات صلة.
- **سلة التسوق** (`/cart`) — تُحفظ في `localStorage` وتبقى بعد إعادة تحميل الصفحة.
- **إتمام الطلب** (`/checkout`) — نموذج شحن وطريقة دفع (نموذج تجريبي، بلا
  بوابة دفع حقيقية بعد).
- **قصتنا** (`/about`) — قصة العلامة، دليل المقاسات، سياسة الشحن والإرجاع، والتواصل.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) لعرض الموقع.

## صور المنتجات

الصور الفعلية للمنتجات موجودة في `public/products/` وهي صور تسويقية جاهزة
(تتضمن اسم القطعة والسعر وزر "ORDER NOW" مصممًا داخل الصورة نفسها). عند
إضافة منتج جديد في `lib/products.ts`، أضيفي صورته إلى هذا المجلد واربطيها
عبر حقل `image`. يُفضّل ضغط الصور الكبيرة قبل رفعها (على سبيل المثال عبر
`sharp`) للحفاظ على سرعة تحميل الموقع.

## الخطوات التالية للإطلاق الفعلي

- ربط بوابة دفع حقيقية تدعم عُمان (مثل Thawani أو Tap) في صفحة `/checkout`.
- تصوير منتج إضافي لكل قطعة (زوايا متعددة، تفاصيل قريبة) بدل الاعتماد على صورة واحدة.
- ربط قاعدة بيانات أو نظام إدارة محتوى لإدارة المنتجات بدلاً من `lib/products.ts`.
- إضافة نظام حسابات المستخدمين وتتبع الطلبات.
